# Screenshots

Screenshots of the working agent. Add images here (PNG preferred) and reference them
from the main README or the docs.

Suggested names, so the files sort in a sensible order:

- `01-welcome.png` – welcome screen with the example questions
- `02-data-answer.png` – a data question with its answer, source period and completeness
- `03-sensitive-question.png` – a sensitive but legitimate question answered factually
- `04-glossary-answer.png` – a Census concept question answered from the glossary
- `05-guardrail-decline.png` – an off-topic or inappropriate request declined
